LAUNCHER GUIDE

How to get started

Follow these steps for a clean first launch.

  1. 01
    Check the game path

    Open Settings and make sure Arma Reforger is detected.

  2. 02
    Choose your mods

    Use Workshop to find content, then add it to a preset.

  3. 03
    Prepare the preset

    Download missing mods and resolve version warnings before a normal launch.

  4. 04
    Join a server

    Choose a server and connect. Arma Reforger downloads missing server mods after it starts.
